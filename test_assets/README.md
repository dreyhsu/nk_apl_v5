# Development Test Assets

This directory contains engineering-only inputs used to simulate an APL
station when production access is unavailable.

- `videos/test1.mp4`: one retained copy of the duplicated `test1.mp4` input.
- `videos/source.mp4`: a second, different local test input.

These files are not Golden Samples, inspection evidence, or production
deployment content. Browser video testing keeps the selected video on the PC
and sends only the selected frame to `Capture & Inspect`.

# Archived VisionEdge Material

This directory preserves reports, reviews and source snapshots inherited from
the original VisionEdge application. The files are not the current NK APL
specification.

Use the project-root `README_APL_ZH.md` for current single-snapshot behavior.
Files under `runtime_backups/` are historical source backups and must not be
loaded as runtime code.

The archive may contain obsolete paths, test counts, workflow descriptions and
first-person engineering notes. Treat it only as traceability material.
